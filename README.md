# 에이전틱 오케스트레이션 명세 — 문서 계열 (SPEC 02–05)

개발 과정을 에이전틱 오케스트레이션으로 전환하기 위한 명세 문서 묶음입니다.
추상에서 구체로 — 개념 → 분해 → 범용 적용 → 프로젝트 정착 순으로 흐릅니다.

## 구성

| 파일 | 내용 |
|------|------|
| `index.html` | **표지/목차** — 다섯 문서 안내 + 각 문서 링크 |
| `spec-02-concepts.html` | 개념서 — 보편 원리 + Voyage 예시 |
| `spec-03-decomposition.html` | Voyage 완전 분해 (5조각·4축) |
| `spec-04-process.html` | 11개 개발 축 범용 적용 |
| `spec-05-voyage.html` | Voyage 11축 정착 |

> SPEC 01(거버넌스 원형 + Phase 1 구현)은 외부 GitHub Pages이며,
> `index.html`에서 외부 링크로 연결됩니다.

## 이식 방법

1. 이 폴더 전체를 프로젝트 안 원하는 위치에 복사합니다.
   예: `docs/specs/` 또는 `voyage-specs/`
2. `index.html`을 브라우저로 열면 표지가 나오고, 거기서 각 문서로 이동합니다.
3. 모든 링크는 **상대 경로**라 폴더째 옮기면 어디서든 작동합니다.
   (단, 파일명은 바꾸지 마세요 — 링크가 파일명을 참조합니다.)

## GitHub Pages로 공개하려면

- 이 폴더를 레포에 올리고 Pages를 켜면 `index.html`이 자동으로 표지가 됩니다.
- 정적 HTML만 있어 빌드 과정이 필요 없습니다.

## 특징

- 단일 HTML 파일들 — 외부 의존성은 Google Fonts뿐
- 모바일 반응형 (좁은 화면에서 사이드바가 토글되고, 표지 카드가 세로로 쌓임)
- 모든 문서가 같은 디자인 시스템을 공유
